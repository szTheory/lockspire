# Lockspire

Shared terms for discussing Lockspire's operator experience and UI quality. [PRODUCT.md](PRODUCT.md) remains authoritative for the domain language shown to operators.

## UI quality planning

**Operator persona**:
A role with a particular level of knowledge and set of jobs in operating a Lockspire provider, such as a support teammate or security reviewer.
_Avoid_: Adopter profile, fictional company

**Adopter profile**:
A synthetic product context describing the kind of application using Lockspire and the circumstances that shape its operator's work.
_Avoid_: Operator persona, observed adopter research

**Scenario**:
A concrete, plausible situation in which a Lockspire operator is trying to complete a particular job, including the relevant starting state and constraints.
_Avoid_: Adopter profile, arbitrary combination of properties

**Story variation**:
A particular presentation of a scenario that makes a meaningful UI state available for inspection.
_Avoid_: Scenario, cosmetic permutation
