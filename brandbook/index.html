01 — Identity

Logo system

A faceted obelisk — light passing through strong structure — paired with a wordmark whose “i” is crowned by a cut signal-stone. The mark and the diamond share one crystalline language. Transparent always; never boxed.

Clear space & minimum size

Keep clear space equal to the height of the mark's plinth on all sides. Minimum legible sizes: wordmark 96px wide; mark 16px (favicon holds down to 16px). Never crowd the lockup with other elements.

Usage rules

✓ Do

Place the mark on transparent or solid brand surfaces. Use the inverse (frost) variant on dark, the default (ink) on light.

✕ Don't

Box the mark in a rectangle, add a drop shadow, or place it on a busy/low-contrast photo.

✓ Do

Keep the diamond cyan even in one-color contexts where possible — it's the signal accent.

✕ Don't

Stretch, rotate, recolor the letters to non-brand hues, or add a tagline to the primary lockup.

✓ Do

Use the mono variants (currentColor) for embossing, single-ink print, or tight UI.

✕ Don't

Separate the mark far from the wordmark or rebuild the lockup with a different font.

07 — Build

Implementation notes

The brand book isn't a parallel universe — its tokens are the product's tokens. Adopt them by consuming tokens/tokens.css (or the same --ls-* names already in admin_css.ex).

Tokens & dark mode

/* Light = :root defaults. Dark = remap semantic aliases only. */
/* Components consume aliases, so dark mode needs zero component edits. */
:root[data-theme="dark"] {
  --ls-surface-page: var(--ls-color-gray-950);  /* Obsidian */
  --ls-text-strong:  var(--ls-color-gray-50);
  --ls-text-accent:  var(--ls-color-brand-500); /* Signal Cyan pops */
  --ls-focus-ring:   var(--ls-color-brand-500);
}

Accent by surface

Use Signal Cyan #22D3EE on dark surfaces and for focus glow / large fills. Use Deep Cyan #0E7490 for text, links, and solid buttons on light (it clears AA; #22D3EE does not). The tokens handle this automatically via --ls-text-accent.
