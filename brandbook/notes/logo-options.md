# Logo — Final System & Tournament Record

## The chosen identity

**Wordmark (primary):** "Lockspire" set in **Familjen Grotesk 600**, with the dot of the
"i" replaced by a **two-tone faceted cyan diamond** — a cut "signal" stone. Outlined to
vector paths (font-independent).

**Mark (icon / favicon / avatar):** a **faceted obelisk / tower** — lit face, shadow face,
plinth, crystalline apex. "Architected trust: light through structure." The diamond tittle
and the tower share one faceted-crystal language, so wordmark and mark are one family.

**Lockup:** tower + wordmark, mark locked to ascender height, tight optical gap.
**Tagline lockup (secondary):** wordmark over "STRUCTURED TRUST FOR PHOENIX" — never primary.

Explicit **ink** (light bg) and **frost** (dark bg) color variants exist alongside the
`currentColor` mono — because GitHub READMEs render logos via `<img>`, where `currentColor`
always resolves to black. Use `<picture>` + `prefers-color-scheme` to swap (see
`../examples/readme-header-example.md`).

## Constraints honored

- **No rectangular cage** — all marks transparent.
- **No subtitle on primary** — tagline is a separate, secondary lockup.
- **Unified mark + wordmark** — shared faceted-crystal language (diamond ↔ tower).
- **Integrated typemark** — the diamond is a motif worked into the letterform, not a
  floating icon.
- **Mono / favicon safe** — `-mono` variants via `currentColor`; tower holds at 16px.

## Tournament record (why this, not the others)

The identity went through six rounds of rendered exploration. Rejected along the way:

- **Blocky rounded-rect marks** (v1) — read as 8-bit / Atari.
- **Full-height spire "i"** (v6) — too tall, unbalanced the wordmark.
- **L-spire initial** (v5) — illegible / detached at size.
- **Converging beams** (v5) — generic triangle read.
- **Nested gateway, arch beacon, ascending signal** (v3–v5) — strong, but the
  **tower + faceted diamond** won on coherence and small-size legibility.

Typeface: **Familjen Grotesk** chosen over Space Grotesk / Sora for warmth + character
while staying architectural.

## Reproducibility

The wordmark/tagline paths were generated by shaping the text in Familjen Grotesk (HarfBuzz
kerning) and outlining glyphs to SVG paths, then SVGO. The tower and diamond are
hand-authored geometry. No font files are committed; see `research.md` for the method and
the OFL note.
