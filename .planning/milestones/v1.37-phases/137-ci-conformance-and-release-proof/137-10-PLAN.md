<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Unprivileged preflight -> protected environment | Artifact data crosses into a secret-bearing job. |
| Protected publish -> public registry | One-way public publication occurs. |
| Runtime logs -> retained artifacts | Secret-adjacent install/OAuth output may be durable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-137-38 | Elevation of privilege | preflight artifact | critical | mitigate | Treat as data; fresh exact-SHA executable checkout; validate schema/checksum before use. |
| T-137-39 | Tampering | publish handoff | critical | mitigate | SHA-bound artifact name and manifest/tar hash verification in both jobs. |
| T-137-40 | Information disclosure | workflow evidence | high | mitigate | Upload only allowlisted validated receipts; keep raw logs/config ephemeral. |
| T-137-41 | Repudiation | release recovery | high | mitigate | Preserve source CI run/SHA and require same artifact identity for retry. |
| T-137-42 | Denial of service | concurrent publication | medium | mitigate | Retain non-canceling release concurrency and protected environment serialization. |
</threat_model>
