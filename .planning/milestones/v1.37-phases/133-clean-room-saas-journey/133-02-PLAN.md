## Trust Boundaries

| Boundary | Description |
|---|---|
| Package installer → host source/database | Generated protocol seams become executable host code and schema. |
| Bootstrap → confidential clients | Two plaintext secrets exist briefly across separate process channels. |
| Bearer/DPoP request → host resource | Untrusted tokens reach Lockspire enforcement then host policy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-133-05 | Elevation of privilege | provider boundary | high | mitigate | Static/provenance audit plus independent compile/verify/HTTP proof prohibits internal seams and replacement routing. |
| T-133-06 | Information disclosure | bootstrap credentials | high | mitigate | Separate mode-0600 channels and sentinels, redacted diagnostics, independent consumption/deletion. |
| T-133-24 | Elevation of privilege | DPoP client policy | high | mitigate | Register a distinct client, update only it through `Lockspire.Admin.update_client/2`, reload through public facade, and keep bearer client unchanged. |
| T-133-07 | Elevation of privilege | protected route | high | mitigate | Canonical plug order, exact audience/scope, durable sender constraint, and separate host policy tests. |
| T-133-08 | Tampering | redirect URI | high | mitigate | Register one exact URI and assert drift rejection over the live authorize endpoint. |
</threat_model>
