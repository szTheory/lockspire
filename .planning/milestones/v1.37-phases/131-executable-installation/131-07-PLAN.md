<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser route/static render → connected LiveView | Untrusted route data reaches a page before authoritative protocol state has been resolved. |
| Deferred LiveView task → ConsentContext | The task carries server-owned socket/account context into the existing subject-bound protocol authority. |
| ConsentContext result → generated HEEx | Only allowlisted review facts or stable error categories may enable/render UI; redirects and failures are terminal. |
| Generated decision form → interaction controller | Action capability becomes available only after valid context and retains normal Phoenix CSRF and supported completion semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-131-25 | Elevation of privilege / Tampering | pre-resolution generated consent render | high | mitigate | Render no approve/deny form or completion target until a successful authoritative context result; prove the disconnected and connected-loading states are non-interactive. |
| T-131-26 | Information disclosure | deferred result and failure rendering | high | mitigate | Consume only existing tagged ConsentContext results, discard task exit reasons, keep stable error copy, and seed/assert non-rendering of sensitive protocol values. |
| T-131-27 | Spoofing | deferred subject-bound load | high | mitigate | Pass only the route identifier and server-owned socket to unchanged ConsentContext subject resolution; do not accept browser-supplied client, subject, scope, or completion facts. |
| T-131-28 | Denial of service | async task exit or duplicate submission | medium | mitigate | Convert task exits to a safe terminal error, schedule one load per connected mount, and preserve dual-control disabling plus native trigger-action completion. |
| T-131-29 | Repudiation | decision completion | medium | mitigate | Keep approval/denial on the existing InteractionController endpoint and its established audit/protocol transition path. |
