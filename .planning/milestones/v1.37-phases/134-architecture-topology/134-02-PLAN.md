<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| RAT-authenticated request → lifecycle service | Self-service mutation must not enumerate or mutate another client. |
| Operator input → lifecycle service | Mutable and immutable fields cross a privileged boundary. |
| Lifecycle service → repository/audit | Credential, client, and evidence writes require atomicity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-134-04 | Spoofing/Elevation of privilege | RFC 7592 URL/RAT binding | critical | mitigate | Preserve invalid-token collapse and active/client-id preconditions before mutation. |
| T-134-05 | Tampering/Repudiation | RAT rotation and audit | critical | mitigate | One replace transaction with forced-failure rollback proof and self-client attribution. |
| T-134-06 | Information disclosure | secret rotation | critical | mitigate | Plaintext returned once, hash/sealed verifier persisted atomically, redacted errors/events. |
| T-134-07 | Elevation of privilege | operator update | high | mitigate | Immutable-field, exact URI/logout, PKCE, and FAPI readiness characterization. |
</threat_model>
