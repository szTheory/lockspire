<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Direct/DCR input → neutral intent | Untrusted client metadata becomes durable security policy. |
| Neutral lifecycle → repository/audit | Client and evidence must commit or roll back together. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-134-01 | Tampering/Elevation of privilege | metadata projection | high | mitigate | Separate direct/DCR intents, shared Shape validation, exact URI/logout and PKCE characterization. |
| T-134-02 | Repudiation/Tampering | DCR create transaction | high | mitigate | Preserve one transact_with_audit call and prove rollback plus DCR actor attribution. |
| T-134-03 | Information disclosure | neutral errors/telemetry | high | mitigate | Safe field/reason outputs and sentinel assertions for secrets, RAT/IAT, and keys. |
</threat_model>
