Prototype-verified `:crypto` contract (RESEARCH "Crypto contract", OTP 27/28/29 identical):
- decrypt accepts truncated tag prefixes (4 and 15 bytes) and returns plaintext -> the envelope parse MUST bind exactly 16 tag bytes and 12 IV bytes before calling `:crypto` (D-19).
- 0-byte IV, 31-byte key, non-binary key/tag RAISE `ErlangError` -> size-guard plus rescue (D-19).
- flipped tag/ct, wrong AAD, wrong key, 0/17-byte tag, 8-byte IV on decrypt return `:error`.
