<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host shell -> Docker Compose | Maintainer env and Compose command choose local port, DB credentials, and mounted paths. |
| Docker network -> Postgres | Phoenix talks to a demo database over an internal Compose network. |
| container filesystem -> host repo | Bind mount exposes the source tree to the container for local iteration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-01 | Information Disclosure | PostgreSQL service | mitigate | Do not publish host port `5432`; keep DB reachable only inside the Compose network by default. |
| T-112-02 | Tampering | bind-mounted repo source | accept | This is a repo-local maintainer demo path; use named volumes for build artifacts and do not present it as production packaging. |
| T-112-03 | Spoofing | public URL vs bind IP | mitigate | Keep `LOCKSPIRE_DEMO_BASE_URL=http://127.0.0.1:4100` and `LOCKSPIRE_DEMO_BIND_IP=0.0.0.0` as separate env values. |
| T-112-04 | Elevation of Privilege | Docker image | mitigate | Do not add production service shape, privileged containers, host Docker socket mounts, or broad host cleanup behavior. |
| T-112-SC | Tampering | package-manager installs | accept | The existing image installs OS build tools, Hex, and Rebar. Do not add new package ecosystems or remote installer curl pipes in this plan. |
</threat_model>
