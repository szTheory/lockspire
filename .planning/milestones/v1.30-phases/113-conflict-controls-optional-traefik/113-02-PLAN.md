## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer shell -> Compose override | Env vars control Traefik hostname, router, service, network, and backend port labels. |
| web service -> external proxy network | The demo web container can be reached by an external local proxy only when the override is included. |
| Traefik hostname -> adoption demo issuer | Hostname routing must preserve the configured browser-visible base URL and exact redirect/issuer alignment. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-113-06 | Spoofing/Tampering | Traefik router/service labels | mitigate | Use configurable hostname/router/service/network labels and deterministic Compose tests proving rendered labels match env values. |
