## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config -> seed data | Normalized demo base URL enters persisted client redirect, registration, interaction, and logout records. |
| seed data -> OAuth redirect validation | Seeded redirect URIs are compared byte-for-byte during authorization and token exchange. |
| smoke env -> HTTP proof | `LOCKSPIRE_DEMO_BASE_URL` drives black-box HTTP requests and expected URL assertions. |
| demo output -> maintainer terminal | Seed output can reveal URLs and client IDs, but must not reveal secrets or tokens. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-111-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager installs are allowed in this plan; if an executor adds one, stop for slopcheck and human verification. |
