<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host application → AdminRouter | The host owns staff authentication and mounts Lockspire's admin router behind its guard. |
| Staff browser → client registration LiveView | Submitted client metadata and filter query values are untrusted; the generated secret is sensitive output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-151-01 | Spoofing | Admin route registration | medium | mitigate | Keep the new route within the existing host-guarded `AdminRouter`; route tests verify the admin route and the public router boundary. |
| T-151-02 | Information Disclosure | Copy-once client creation result | high | mitigate | Keep plaintext in the same LiveView response only; test acknowledgement and route departure clearing; exclude credential values from screenshots and URLs. |
| T-151-03 | Tampering | Return-filter query | low | mitigate | Normalize filter inputs and construct only the internal inventory path; do not accept a caller-supplied destination. |
| T-151-SC | Tampering | Package installation | low | accept | No package-manager changes or third-party dependencies are needed in this plan. |
</threat_model>
