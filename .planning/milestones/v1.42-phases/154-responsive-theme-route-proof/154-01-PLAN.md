## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rendered admin page -> saved image/evidence | Anything visible on screen persists into tmp/ images and tracked markdown rows. |
| Capture script -> stateful admin controls | A stray click or Enter could rotate, revoke, or generate credentials in the demo. |
| Local tooling -> CI | A real-browser script in CI would be flaky and depend on a global CLI. |
