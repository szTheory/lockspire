<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IAT domain data -> rendered HTML | IAT metadata may be shown; plaintext IAT secret is allowed only in the immediate copy-once result state |
| Operator event -> IAT mint/revoke APIs | Existing mint/revoke events must preserve confirmation, copy-once, and storage semantics |
| DCR onboarding copy -> operator policy decision | UI copy must not collapse DCR onboarding into issuer DCR policy or imply broader registration behavior |

## ASVS Level 1 / High-Block Gate

| Gate | Handling |
|------|----------|
| Baseline | OWASP ASVS 5.0.0 Level 1 |
| Block condition | Block plan completion on any unresolved HIGH issue in applicable ASVS categories. |
| Applicable categories | V4 Access Control for host-owned admin boundary preservation; V5 Input Validation for existing IAT form/event handling; V6 Cryptography for copy-once IAT display and secret redaction; V14 Configuration for DCR onboarding/policy posture clarity. |
| Executor handling | If implementation or tests reveal a HIGH security issue, stop execution and fix it before writing the summary; escalate only if the fix would require out-of-scope protocol, schema, or host-auth changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-109-13 | Information Disclosure | IAT inventory and mint result | mitigate | render plaintext only through `copy_once_secret_panel` immediately after mint; assert no plaintext remains after acknowledge and no inventory row reveals secret material |
| T-109-14 | Tampering | IAT revoke event | mitigate | preserve existing `revoke` event and domain API; use consequence-specific confirmation copy for `Revoke initial access token` |
| T-109-15 | Repudiation | DCR/IAT copy | mitigate | preserve locked `DCR onboarding` versus `DCR policy` vocabulary and route CTAs so operators can distinguish intake from issuer posture |
| T-109-16 | Denial of Service | mobile IAT inventory | mitigate | use `resource_item` and `long_value` for long labels, IDs, creator values, and timestamps |
| T-109-SC | Tampering | package manager installs | accept | no dependency installation or package-manager task is allowed in this plan |
