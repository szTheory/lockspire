# Milestone v1.33: OSS Adoption Trust

**Status:** IMPLEMENTED IN WORKTREE 2026-06-30
**Focus:** Public surface clarity, installer verifier truth, package hygiene, and adoption-demo support boundaries.

## Overview

v1.33 tightens the parts most likely to make an OSS adopter lose trust before production: unclear admin route protection, verifier blind spots, package junk, and demo docs that could be mistaken for a supported deployment model.

## Delivered

- Public `Lockspire.Web.Router` no longer exposes admin LiveView routes.
- `Lockspire.Web.AdminRouter` remains the operator surface and must be mounted separately by the host app.
- `Lockspire.Install.Verify` now checks public mount, admin mount, device verification route, pending migrations, and prefix-aware table presence.
- Install generator tests assert the guarded `/lockspire/admin` mount and default storage-prefix config.
- Package files are narrowed to source, migrations, templates, docs, package metadata, and license.
- Release-readiness contracts now catch `.bak`, `.DS_Store`, and `priv/plts` package leakage.

## Open Follow-Up

- A full README quality rewrite is still a separate adoption-DX milestone if the project wants it. The current implementation only patches the highest-risk trust gaps.
