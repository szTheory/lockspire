## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| official linter release artifacts → CI runner | Downloaded binaries execute against trusted repository workflows and scripts. |
| dependency resolvers → checked-in locks | Mix/npm setup may otherwise rewrite the dependency graph being verified. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-126-16 | Tampering | downloaded lint tools | high | mitigate | Pin exact versions and verify hardcoded SHA256 before extraction/execution. |
| T-126-17 | Tampering | lockfile verification | high | mitigate | Use check-locked resolution and explicit git diff gates over every authoritative lockfile. |
| T-126-18 | Repudiation | ignored lint findings | medium | mitigate | Use one checked-in command, no warning suppressions, and required CI execution. |
| T-126-19 | Denial of service | tool bootstrap | low | accept | Official artifact availability is required only when exact local tools are absent; failure is visible and safe. |
| T-126-SC | Tampering | npm package installs | high | mitigate | Runtime `npm ci` consumes the Plan 03 audited lock with scripts disabled and does not introduce packages. |
</threat_model>
