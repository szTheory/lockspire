## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent tests → process-global application env | Test mutations can leak across cases unless serialized and restored exactly. |
| test process → shared PostgreSQL sandbox | Ownership errors can expose or roll back another test's data. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-130-05 | Tampering | DataCase | high | mitigate | Use sandbox owner lifecycle scoped to the test process rather than global mode mutation. |
| T-130-06 | Information Disclosure | test failures | low | accept | Helpers operate only on test configuration and do not print values during cleanup. |
</threat_model>
