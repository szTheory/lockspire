<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host Ecto Repo → Lockspire protocol core | A host-owned database module must never be treated as a Lockspire domain storage adapter. |
| persisted signing key → CIBA Push payload | Private key material is used to sign tokens and must fail closed without entering logs or response payloads. |
| Lockspire worker → RP notification endpoint | Tokens cross the network only in the existing authenticated Push payload. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-128-01 | Elevation of privilege | `AccessTokenSigner.fetch_signing_key/1` | high | mitigate | Default to the behavior-implementing Repository and retain explicit key-store injection and active-key validation. |
| T-128-02 | Information disclosure | signer and worker failure paths | high | mitigate | Preserve structured errors and current redaction; tests inspect token shape without exposing key material. |
| T-128-03 | Tampering | CIBA Push token assertions | high | mitigate | Require compact signed JWT shapes for both access and ID tokens in the ordinary-host-repo E2E path. |
</threat_model>
