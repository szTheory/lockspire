<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plaintext RAT/IAT → hashed persistence | Copy-once bearer credentials must never be stored or logged in plaintext. |
| protocol/admin orchestration → transactional adapter | Client mutation and audit, and IAT redemption, must stay atomic under concurrency. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-128-10 | Tampering | DCR update and RAT rotation | critical | mitigate | Keep row locks, hash replacement, and audit append in one Repository transaction and test rollback. |
| T-128-11 | Information disclosure | RAT/IAT lifecycle | critical | mitigate | Preserve hash-only persistence, sensitive-query suppression, copy-once returns, and enumeration-resistant errors. |
| T-128-12 | Repudiation | DCR management audit | high | mitigate | Preserve existing audit actions and make mutation plus audit atomic inside the adapter. |
</threat_model>
