# Phase 116 Route And Workflow Inventory

This inventory is source-derived from `Lockspire.Web.AdminRouter` for normal mounted routes. It publishes operator-readable `/admin...` paths only; host-specific mount prefixes such as `/lockspire/admin` are host integration details, not canonical route truth.

The only Phase 116 workflow exception is `/admin/clients/:client_id/edit?workflow=logout-propagation`. It is URL/query workflow truth in `ClientsLive.Show` and `docs/operator-admin.md`, not a Phoenix route or router expansion.

## Surface Classification Vocabulary

| Classification | Meaning |
|----------------|---------|
| `admin_supported` | Host-guarded Lockspire admin surface backed by `Lockspire.Web.AdminRouter` or a documented query workflow on an admin route. |
| `demo_only` | Demo fixture or adoption-demo proof. Not public support truth. |
| `test_only` | ExUnit/source contract or test fixture proof. Not runtime behavior. |
| `internal_lab` | Maintainer-only lab/stress surface. Never public admin support truth. |

## Operation Queue Boundary

`/admin/interactions`, `/admin/device_authorizations`, and `/admin/logouts` are inventory and support-review surfaces in Phase 116. Their rows intentionally say read-only support truth because this phase does not add retry, discard, logout, or other operation-queue UI unless an existing domain API already backs the action.
