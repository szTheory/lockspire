<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local repository and remote origin → collector | Mutable Git metadata and adversarial ref/path text enter the Bash process. |
| Collector → canonical Markdown | Untrusted command output is normalized into a durable maintainer artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-138-01 | Tampering | `collect_git_baseline` fetch policy | high | mitigate | Allow only `git fetch --prune --tags "$remote"`; contract-test rejection/absence of tag pruning, deletes, resets, checkouts, and worktree mutation. |
| T-138-02 | Tampering / Elevation | ref/path rendering | high | mitigate | Quote expansions, forbid `eval`, normalize through explicit functions, and hermetically exercise shell/Markdown metacharacter fixtures. |
| T-138-03 | Repudiation | source receipts and divergence | high | mitigate | Record immutable SHAs, exact command/scope/exit status, collection bounds, limitations, and fail-visible completeness before drawing conclusions. |
| T-138-04 | Denial of service | concurrent/interrupted output | medium | mitigate | Per-target exclusive lock, same-directory temp file, cleanup trap, overwrite refusal, and atomic rename prevent truncation and writer races. |

## ASVS L1 Control Mapping

| Trust Boundary / Threats | ASVS L1 Control Area | Planned Control and Verification |
|--------------------------|----------------------|----------------------------------|
| Local repository and remote origin → collector (`T-138-01`, `T-138-03`) | V4 Access Control; V7 Error Handling and Logging | Constrain collection to the read-only Git command allowlist plus the single D-09 fetch, and preserve exact command/exit/scope/SHA receipts; contract tests and source review must prove forbidden mutations are absent and failures cannot yield a complete/clean conclusion. |
| Collector → canonical Markdown (`T-138-02`, `T-138-04`) | V5 Validation, Sanitization and Encoding; V12 Files and Resources | Quote shell inputs, forbid `eval`, escape/redact rendered values, and use an exclusive target lock plus same-directory atomic rename; metacharacter, overwrite, concurrency, and interrupted-render fixtures must pass. |
