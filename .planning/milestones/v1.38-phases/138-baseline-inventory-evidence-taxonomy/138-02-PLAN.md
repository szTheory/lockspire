## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local authenticated `gh` → GitHub GraphQL | Repository identity and read-only queue queries cross an authenticated external boundary. |
| GitHub JSON → temporary pages → Markdown | Adversarial titles/status text and incomplete pagination enter a durable artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-138-05 | Information disclosure | PR/issue renderer | high | mitigate | Query and render an explicit safe-field allowlist, redact secret sentinels, omit bodies/comments/logs/env/token data, and delete private temp pages on exit. |
| T-138-06 | Repudiation | GraphQL pagination | high | mitigate | Record auth, repository, scope, exit, page/item counts, and terminal pageInfo; partial/malformed pages cannot produce complete or zero conclusions. |
| T-138-07 | Tampering / Elevation | GitHub text through shell/Markdown | high | mitigate | Avoid `eval`, pass query/arguments safely, parse only with jq, and escape/redact every rendered string under adversarial fixtures. |
| T-138-08 | Spoofing | repository/auth selection | medium | mitigate | Resolve and record canonical repository identity and `gh auth status`; mismatch or missing auth makes GitHub sources unavailable. |
