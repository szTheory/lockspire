## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git selector process → maintained completeness | Command exit and output must be separated so failures cannot masquerade as empty evidence. |
| Tracked path bytes → shell/parser/Markdown/filesystem | Valid but hostile Git filenames cross multiple delimiter and rendering boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-138-33 | Repudiation | maintained selector exits | high | mitigate | Capture real exit codes before parsing, emit family-specific failure receipts, and downgrade aggregate completeness under executable fixtures. |
| T-138-34 | Tampering / Elevation | tracked path transport | high | mitigate | Use NUL-delimited Git output, exact quoted internal paths, no command substitution for NUL data, and hostile filename fixtures with side-effect assertions. |
| T-138-35 | Information disclosure / Tampering | receipt and Markdown rendering | high | mitigate | Apply credential/control/Markdown sanitization to every displayed path, selector, receipt, evidence reference, and derived filename fragment. |
| T-138-36 | Denial of service | malformed/ambiguous maintained records | medium | mitigate | Preserve bounded fragments and family scope, route ambiguity to partial receipts, and retain usable siblings without broad scanning. |
