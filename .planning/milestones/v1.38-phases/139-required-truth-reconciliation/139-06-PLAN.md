## Trust Boundaries

| Boundary | Description |
|---|---|
| Host receipt -> candidate SHA | GSD-sealed phase/identity/hook/writer/transformation state must identify the only candidate allowed to move main. |
| Local candidate -> origin main | A normal fast-forward push crosses repository authority and must reject races/non-ancestry. |
| GitHub/Hex -> acceptance receipt | Mutable external data is untrusted until exact ids, repository, SHA, status, tag, version, and checksum match. |
| Live evidence -> Git-common-dir receipt | Only allowlisted redacted values may persist outside tracked history through an atomic mode-0600 write. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-139-26 | Tampering | main ref landing | high | mitigate | Require exact ancestors, compare-and-swap local update, non-force push, re-fetch, and concurrent-advance rejection. |
