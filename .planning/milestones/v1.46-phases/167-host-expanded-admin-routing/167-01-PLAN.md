<public_contract>
Use require Lockspire.Web.AdminRoutes and its qualified lockspire_admin_routes/2 macro; importing that macro is also supported. Its first argument is a literal nonempty slash-prefixed admin route path, composed with the current Phoenix scope, never treated as an escape to router root. A root-level /lockspire/admin and /admin within scope /lockspire are equivalent declarations in separate routers. Obtain the effective path with the public Phoenix.Router.scoped_path/2 API. Normalize a trailing slash and require the effective path to end in the literal segment /admin. Reject doubled separators, dot segments, parameter/wildcard segments, backslashes, encoded separators, query/fragment and scheme/authority forms in either literal or effective path. Do not strip a repeated enclosing prefix: a double-prefixed declaration remains double-prefixed and is rejected by the runtime alignment guard when config names the single prefix.

Required options are a nonempty list of host pipeline atoms in pipe_through and one host module/tuple hook or a nonempty ordered list in on_mount. The first host hook owns current staff authorization. Preserve the host hook sequence, then append {Lockspire.Web.AdminMount, {:mount_path, effective_admin_path}}. Run supplied HTTP pipelines in order before an internal mount-alignment pipeline. Neither a conn assign nor a session boolean substitutes for host identity resolution. Unknown/duplicate option keys, absent/empty wiring and malformed option values fail compilation. Do not validate by executing host callbacks during compilation.

The native live_session name is always :lockspire_admin. Do not expose a session-name option or create user-derived atoms. A duplicate declaration, an existing name collision or nesting inside another live_session fails through native Phoenix validation. The only additional options are root_layout, layout and session. Omitted layout options inherit native behavior; supplied {module, template} or false values pass through. session accepts a string-keyed map or {module, function, args} MFA, merged by native LiveView with the host session; it configures additional signed mount data, never Plug.Session or websocket cookies. Preserve callback invocation timing and args, and reject malformed shapes at compile time without executing an MFA.

Lockspire.Web.AdminRoutes.__admin_live_routes__/0 is doc-hidden inventory expansion used by the public macro and retained AdminRouter. Preserve the exact current declaration order, 29 path/verb/LiveView/action tuples, including both overview aliases. AdminRouter retains its module and relative routes; forwarded connected usage remains the negative fixture. No private Phoenix join/path patch is permitted.

Lockspire.Web.AdminMount implements Plug init/1 and call/2 plus on_mount/4 only for mount alignment. Compare the bound compiled admin path with canonical Lockspire.mount_path() plus /admin at HTTP and disconnected/connected entry. On mismatch or missing/invalid config raise a controlled ArgumentError identifying the two paths and configuration key, without session/token content; do so before the LiveView mount. Do not read runtime.exs configuration during macro expansion or require it to exist at compilation. Host staff policy continues to run independently and first.
</public_contract>
