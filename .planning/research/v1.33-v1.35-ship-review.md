# v1.33-v1.35 Ship Review

Date: 2026-06-30

## Scope

This review covered the completed v1.33-v1.35 worktree before packaging it for public review:

- v1.33 OSS adoption trust and public/admin route separation.
- v1.34 prefix-isolated storage defaults.
- v1.35 CI/CD efficiency and release-readiness cleanup.

The repo was already between GSD milestones with a dirty worktree on `milestone/v1.28-admin-ui-operator-experience-polish`, so this was a local ship-hardening pass rather than a PR creation pass.

## Fixes Made During Review

- Tightened `Lockspire.Install.Verify` so it detects missing guarded admin mounts and rejects a public Lockspire router mount that appears before the admin router and shadows `/admin`.
- Fixed `mix lockspire.verify` migration inspection to handle the current `Ecto.Migrator.with_repo/2` return shape and to perform prefix table checks while the repo is started by `with_repo/2`.
- Removed overly broad CI and release cache restore keys that could restore `_build` or PLT cache entries across incompatible OTP/Elixir pairs.
- Changed Hex package file selection from broad directory globs to an exact allowlist of packageable files.
- Excluded local test-only modules/tasks from the package: `Lockspire.TestRepo` and `Mix.Tasks.Lockspire.Test.Setup`.
- Ignored `.planning/research/.cache/` and removed local `.DS_Store` artifacts from the worktree.
- Updated package-boundary/design contract tests to inspect the actual Mix package config instead of regex-matching old `mix.exs` source text.

## Remaining Shipping Blockers

- The branch name still reflects an older milestone (`milestone/v1.28-admin-ui-operator-experience-polish`), while the worktree now contains v1.33-v1.35 scope.
- The worktree contains many pre-existing dirty files, so a single blind commit would mix unrelated history and make review harder.
- The active GSD state is between milestones and has no current phase verification artifact to attach to `gsd-ship`.

## Recommended Next Move

Create a clean PR branch from the intended base, stage the v1.33-v1.35 files intentionally, and open one reviewable PR with this ship review attached as evidence. If the dirty worktree needs to be preserved, split unrelated pre-existing changes before committing this work.
