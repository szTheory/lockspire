# Quick Task 260925-x8y: Classify valid in-progress UAT status

## Objective

Extend the existing structured UAT lifecycle classifier so a valid `status: testing` record is represented as active work with a recheck trigger. Keep status as lifecycle evidence only: it must not turn pending UAT checks into passes or alter the live UAT artifact, canonical ledger, or Phase 140 gate.

## Current evidence

The existing 260924-mhp classifier maps `complete` to `resolved/already-resolved/direct_current`, `partial` to `active/defer-with-trigger/direct_current`, and rejects invalid or missing structured status. The tracked Phase 138 UAT currently has `status: testing`; current test 100 is awaiting a user response and has `result: pending`, and test 101 also has `result: pending`. The summary reports 99 passed, 2 pending, and 0 issues. The collector therefore marks this exact UAT record unclassified/ambiguous even though its required UAT structure is present. This task changes classifier behavior and fixtures only; it does not resolve either pending check or claim UAT completion.
