<objective>
Kill the tautology this phase exists to kill: prove `mix lockspire.install` against a real,
committed `mix phx.new` host so app name, web module, router module, scope module, and repo
module all resolve from the host rather than from Lockspire.

Purpose: `install_generator_test.exs:363-368` wraps the task in `File.cd!`, which changes the
working directory but never the Mix project, so `build_assigns/1` still answers `:lockspire`.
The two module values the test asserts are the same values the test supplied via `--web` and
`--scope`, and the `repo:` line is not asserted at all. This plan puts the generator in the
adopter's position and reads what the real derivation chain says.

Output: a committed trimmed `phx.new` snapshot with documented provenance, a scratch-copy /
tree-checksum test helper, an `@moduletag :integration` host-interaction proof driven by
`Mix.Project.in_project/4` with no module flags, and the manifest `version` field corrected to
record Lockspire's version rather than whichever project happened to be pushed.
</objective>

  a reading of the requirement, not a fact.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
