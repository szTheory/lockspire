<objective>
Let a host write a key entry as `{id, {:system, "VAR"}}` (KEK-05): `Lockspire.Config` reads the
variable at runtime, and an unset or empty variable aborts boot with an error naming the variable,
never its value, and never degrading to "not configured". Prove that a resolved key set never shows
key bytes or env values in inspect or logs (KEK-06, D-08).

Purpose: a host cannot silently boot without encryption because a secret was missing from one node.
Output: env-entry resolution and missing_env error in `config.ex`; resolution, boot and redaction
tests.
</objective>
