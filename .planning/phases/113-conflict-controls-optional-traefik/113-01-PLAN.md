<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer shell -> Docker Compose | Untrusted env vars and CLI flags render container, port, network, and volume configuration. |
| reset helper -> Docker daemon | Local shell command can stop containers and remove Docker volumes. |
| browser/smoke -> adoption demo | Public base URL controls issuer, redirect, endpoint, and smoke proof alignment. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-113-01 | Spoofing/Tampering | `examples/adoption_demo/docker-compose.yml` public URL and port env | mitigate | Keep `LOCKSPIRE_DEMO_BASE_URL` as the explicit browser-visible URL truth and prove rendered `PORT`, host mapping, and base URL alignment with contract tests. |
| T-113-02 | Information Disclosure | `db` Compose service | mitigate | Keep default `db.ports` absent; put host DB access only in `examples/adoption_demo/docker-compose.db-host.yml` using `LOCKSPIRE_DEMO_DB_HOST_PORT`. |
| T-113-03 | Denial of Service | `examples/adoption_demo/bin/docker-reset` | mitigate | Remove only active project volumes ending in `db_data`, `deps_volume`, and `build_volume`; forbid prune commands and hard-coded default volume prefixes. |
| T-113-04 | Tampering | Lockspire protocol/runtime modules | mitigate | Do not modify protocol core, storage, generators, Plug/Phoenix integration, admin behavior, OAuth/OIDC flows, redirect validation, PKCE, token lifecycles, algorithms, or redaction. |
| T-113-SC | Tampering | Package installs | accept | No npm, pip, cargo, Hex, or Mix package install task is planned; RESEARCH.md Package Legitimacy Audit lists no packages. |
</threat_model>
