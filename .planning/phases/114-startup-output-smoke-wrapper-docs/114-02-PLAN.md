<threat_model>
Security posture: Phase 114 uses an ASVS Level 1 posture with a high threshold for introducing new risk; this plan only wraps existing local smoke proof and must not expand token handling or logging.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer environment -> smoke wrapper | `LOCKSPIRE_DEMO_BASE_URL` controls the target origin for local smoke proof. |
| shell wrapper -> Python smoke | Wrapper delegates proof to existing script with normalized environment. |
| maintainer terminal -> copied proof | Smoke target output may be shared in issues or logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-114-05 | Spoofing | `scripts/demo/adoption_smoke.sh` target URL | mitigate | Echo the normalized target and pass it through `LOCKSPIRE_DEMO_BASE_URL`; existing Python smoke asserts issuer/callback/device URL drift. |
| T-114-06 | Tampering | Wrapper proof logic | mitigate | Wrapper must exec existing Python smoke and avoid duplicating OAuth/OIDC parsing or token handling. |
| T-114-07 | Information Disclosure | Smoke wrapper output | mitigate | Wrapper prints only target URL and delegates; it must not print tokens, cookies, codes, or raw response bodies. |
| T-114-08 | Denial of Service | Runtime Docker smoke | accept | Smoke is maintainer-local and bounded by existing Python readiness timeout; no production runtime is affected. |
| T-114-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install tasks are planned; package legitimacy audit lists no additions. |
</threat_model>
