<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Packaged migration directory → host filesystem | Package-owned schema files enter a host-owned deployment path. |
| Host migration inventory → installer decision | Arbitrary pre-existing host filenames/content must never be treated as safe overwrite targets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-131-05 | Tampering | migration apply | high | mitigate | Validate the complete source/destination inventory before mkdir/copy and reject all identity/content collisions. |
| T-131-06 | Tampering | existing host migration | high | mitigate | Treat host files as authoritative and immutable; equal bytes are unchanged and unequal bytes fail. |
| T-131-07 | Denial of service | malformed package migration | medium | mitigate | Reject unparseable packaged filenames during preflight with an internal package-integrity error. |
| T-131-08 | Information disclosure | collision diagnostics | low | mitigate | Report paths, collision class, version/name, and remediation without logging migration contents. |
