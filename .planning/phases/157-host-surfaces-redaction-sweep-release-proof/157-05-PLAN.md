<objective>
Close the decode half of RED-01: a malformed sealed private key can never make the JOSE library raise with decoded private bytes inside an exception that then reaches a log, a crash report or `oban_jobs.errors`. Implements D-04 inside D-00 and SAFE-01.

Plan shape: D-17's redaction plan was split on file budget into two wave-1 plans with disjoint files. 157-01 owns the store, schema, Redaction, the single `KeyMaterialMatcher` and the sweep; this plan (157-05) owns `PrivateJwk.to_jwk/1` and the six consumer swaps. Because 157-01 runs in the same wave, this plan does not use the matcher; its tests prove the error contract and that nothing raises. The leak proof for the malformed key (logs, exception text, Oban job errors) runs through the matcher in 157-06 (wave 2), which depends on both plans.

Purpose: one guarded boundary between decoded key maps and JOSE, shared by every consumer, with unchanged external errors.
Output: `PrivateJwk.to_jwk/1`, six consumer swaps, malformed-key test case per consumer.
</objective>
