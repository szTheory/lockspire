<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maintainer shell -> Docker daemon | Local commands can stop or delete resources on the developer host. |
| Maintainer shell -> repo filesystem | Cleanup can remove generated files under the checkout. |
| Script output -> maintainer terminal/logs | Output must avoid sensitive material while providing exact remediation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-115-01 | Tampering | `docker-stop` / `docker-reset` | mitigate | Preserve volumes on stop; reset deletes only exact active-project `db_data`, `deps_volume`, and `build_volume`. |
| T-115-02 | Tampering | `docker-cleanup` | mitigate | Dry-run default plus `--execute`; deletion allowlist is exact active-project volumes and named generated artifact paths only. |
| T-115-03 | Information Disclosure | cleanup/lifecycle output | mitigate | Output may show project/resource/path names but must not show secrets, tokens, private keys, authorization codes, refresh tokens, cookies, or unredacted sensitive values per D-17. |
| T-115-04 | Denial of Service | local developer Docker state | mitigate | Forbid host-wide prune commands and broad Compose volume deletion; labels are reporting-only, not destructive selectors. |
| T-115-SC | Tampering | package installs | accept | No package-manager installs are planned in this plan. |
</threat_model>
