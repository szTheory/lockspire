Create `lib/lockspire/web/live/admin/keys_live/protection.ex` defining `Lockspire.Web.Live.Admin.KeysLive.Protection` with `@moduledoc false`. It holds `@type state` (the seven atoms listed in interfaces) and a public `@spec summarize(term()) :: summary()`, where `summary()` is a map with the keys state, tone, value, detail and command. summarize/1 is pure and never raises.

Clause order implements D-02 precedence:
1. `summarize({:error, {:invalid_config, _message}})` returns invalid_config. It discards the message.
2. `summarize({:ok, %{configured: false}})` returns not_set_up.
3. `summarize({:ok, %{configured: true} = status})` classifies the status map in this order:
   - unreadable, when `status.unknown_kek != %{}` or `status.undecryptable > 0`.
   - unencrypted, when `status.legacy > 0`.
   - older_key, when `Map.keys(status.by_kek_id)` contains any id other than `status.current_kek_id`.
   - encrypted otherwise. Use `Map.get` with safe defaults (%{} and 0) so a missing key never raises.
4. A final catch-all `summarize(_other)` returns could_not_check. It covers repo_not_started, storage_unavailable, `:error` and any unexpected term.

Never read stranded_retired, pending, configured_kek_ids or legacy_plaintext (D-04, D-08).
