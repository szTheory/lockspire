## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-132-01 | Elevation of privilege | AccessToken/VerifyToken scope and audience normalization | high | mitigate | Use one implementation and signed-JWT parity tests for scalar/list/missing/malformed values and exact error taxonomy. |
| T-132-02 | Spoofing | confirmation normalization | high | mitigate | Allowlist only nonblank JKT and certificate-thumbprint members and prove VerifyToken derives identical binding requirements. |
| T-132-03 | Information disclosure | public confirmation reader | medium | mitigate | Return a new normalized map containing only semantic binding values; never return the raw nested map or arbitrary members. |
