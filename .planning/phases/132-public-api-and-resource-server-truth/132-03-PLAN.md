| HTTP DPoP proof → protected-resource Plug | Attacker-controlled proof identity crosses into replay enforcement. |
| Protocol replay object → configured/custom store | Security state must be durable or explicitly delegated and failures must not weaken enforcement. |

| T-132-10 | Tampering | custom replay-store failure | high | mitigate | Never fall back after override errors; map errors to invalid proof and assert binding remains unverified. |
| T-132-11 | Elevation of privilege | incompatible store override | high | mitigate | Validate the behavior capability or fail closed before token acceptance. |
| T-132-12 | Denial of service | replay persistence | medium | mitigate | Retain bounded proof age, indexed unique replay key, pruning, and generic failure output. |
