<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub GraphQL namespaces → aggregate collector | Independently successful or failed PR/issue results must become one fail-closed snapshot decision. |
| Normalized GitHub rows → proposal renderer | Remote row fields must be complete and sanitized before they can support any disposition. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-138-25 | Tampering / Repudiation | `collect_github_inventory` aggregate | high | mitigate | Buffer both namespaces, preserve independent receipts, compute aggregate status once, and gate all affirmative dispositions on both namespaces being complete. |
| T-138-26 | Tampering | pre-render row validation | high | mitigate | Validate required immutable identity/state/type fields for every normalized row before rendering; malformed combinations become namespace-specific partial evidence. |
| T-138-27 | Information disclosure | buffered GitHub pages and rows | high | mitigate | Retain the existing safe-field allowlist, boundary sanitizer, private collector-owned buffers, and exit cleanup; hostile fixtures prove no raw secret/control payload survives. |
| T-138-28 | Denial of service | two-namespace collection | low | accept | Queries remain bounded per page and use the existing cursor pagination; sequential namespace collection is acceptable for this maintainer-only command and failures remain receipt-visible. |

## OWASP ASVS L1 Control Mapping

| V5 Validation, Sanitization and Encoding | Every remote row and rendered field is untrusted. | T-138-26 and T-138-27; Task 2 validates normalized rows before reusing the existing sanitizer and renderer. | Malformed-row and hostile-valid fixtures pass the focused ExUnit command without row shifting or payload leakage. |
| V7 Error Handling and Logging | Namespace and row failures must retain exact causes and fail closed. | T-138-25 and T-138-26; both tasks preserve namespace-specific receipt codes and aggregate limitations. | PR-success/issue-failure, pagination-failure, and malformed-row combinations each produce deterministic partial receipts. |
