<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git observations → stable identity helper | Canonical ref/path subjects depend on a subprocess result before entering durable evidence. |
| Stable identity result → domain receipt | Missing identity must become explicit incomplete evidence rather than silent row loss. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-138-29 | Tampering / Repudiation | `stable_evidence_id` result | high | mitigate | Validate subprocess exit and full digest shape; propagate a typed failure to the exact domain receipt. |
| T-138-30 | Repudiation | branch/tag/worktree loops | high | mitigate | Replace all skip/ignore paths with domain failure flags, partial receipts, aggregate incomplete status, and executable fixtures for every call site. |
| T-138-31 | Tampering | fallback identity temptation | medium | mitigate | Preserve kind-plus-canonical-subject hashing and reject positional/random/mutable fallback IDs through source and repeat-run contracts. |
| T-138-32 | Denial of service | hash subprocess failure | low | accept | One failed identity marks only the affected domain partial while retaining safely identified sibling rows and an exact recovery limitation. |
