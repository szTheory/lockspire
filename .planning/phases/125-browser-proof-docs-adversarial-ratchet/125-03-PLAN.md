|---|---|
| route-local fixtures -> rendered Support/Operate HTML | Synthetic route data crosses into rendered LiveView output and must remain redaction-safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-125-09 | Information Disclosure | Support and Operate route tests | mitigate | Seed sensitive-adjacent values and assert rendered HTML omits plaintext tokens, secrets, device/user codes, cookies, raw protocol values, and production-looking identifiers. |
| T-125-10 | Tampering | Operate queue rendered controls | mitigate | Assert no unsupported retry/discard/approve/deny/logout-now/worker-control UI appears on read-only pages. |
| T-125-11 | Denial of Service | long Support/Operate values | mitigate | Assert long IDs, scopes, endpoint URLs, handles, and status notes render through wrapping primitives and remain readable. |
| T-125-12 | Repudiation | stale or unbacked route proof | mitigate | Keep tests mounted against existing LiveViews and route-local fixtures rather than screenshot filenames or browser-only evidence. |
</threat_model>
