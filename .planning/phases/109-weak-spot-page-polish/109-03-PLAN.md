## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository/Admin reads -> queue HTML | Durable operation state crosses into operator UI and must stay non-secret and readable |
| Queue state -> operator action labels | UI must not imply unsupported retry, discard, approve, deny, or mutation behavior |
| Long operational identifiers -> mobile layout | Delivery IDs, endpoint URLs, interaction IDs, timestamps, and client IDs must wrap without page-level overflow |

## ASVS Level 1 / High-Block Gate

| Gate | Handling |
|------|----------|
| Baseline | OWASP ASVS 5.0.0 Level 1 |
| Block condition | Block plan completion on any unresolved HIGH issue in applicable ASVS categories. |
| Applicable categories | V4 Access Control for host-owned admin boundary preservation; V5 Input Validation for existing read-only loader/event boundaries; V6 Cryptography for code/secret/verifier redaction; V9 Communications for endpoint URL display without new network action. |
| Executor handling | If implementation or tests reveal a HIGH security issue, stop execution and fix it before writing the summary; escalate only if the fix would require out-of-scope protocol, schema, or host-auth changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-109-09 | Information Disclosure | operations rows | mitigate | render only non-secret client/account/status/timestamp/endpoint/durable ID context; assert user-code, device-code, hash, secret, and verifier material are absent |
| T-109-10 | Tampering | unsupported queue actions | mitigate | do not add retry/discard/approve/deny events unless an existing domain API is wired in the same task; otherwise render review/pivot context only |
| T-109-11 | Repudiation | queue action copy | mitigate | if an existing action is rendered, copy must name delivery/client/endpoint/status/consequence; otherwise no mutation action is shown |
| T-109-12 | Denial of Service | mobile operations rows | mitigate | use `resource_item` and `long_value` for long IDs, endpoint URLs, and timestamps; avoid raw table-first primary scanning |
| T-109-SC | Tampering | package manager installs | accept | no dependency installation or package-manager task is allowed in this plan |
