<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params -> token list query | Untrusted account/client/status filters enter LiveView and must stay normalized before `Admin.list_tokens/1` |
| Token domain data -> rendered HTML | Durable token metadata crosses into operator HTML and must be redacted and wrapped |
| Operator confirmation -> revoke APIs | Dangerous token revocation events must require explicit confirmation and name non-secret target context |

## ASVS Level 1 / High-Block Gate

| Gate | Handling |
|------|----------|
| Baseline | OWASP ASVS 5.0.0 Level 1 |
| Block condition | Block plan completion on any unresolved HIGH issue in applicable ASVS categories. |
| Applicable categories | V4 Access Control for host-owned admin boundary preservation; V5 Input Validation for existing URL filter normalization; V6 Cryptography for token/secret redaction and no plaintext exposure. |
| Executor handling | If implementation or tests reveal a HIGH security issue, stop execution and fix it before writing the summary; escalate only if the fix would require out-of-scope protocol, schema, or host-auth changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-109-01 | Information Disclosure | `TokensLive.Index` and `TokensLive.Show` | mitigate | render only durable non-secret handles and redacted values; add LiveView assertions that token plaintext, hashes, secrets, user codes, and verifier material are absent |
| T-109-02 | Tampering | `revoke_token` and `revoke_family` events | mitigate | preserve checkbox guard clauses, separate danger confirmation panels, existing Admin APIs, and consequence-specific copy per D-18/D-19 |
| T-109-03 | Denial of Service | mobile token rows with long identifiers | mitigate | use `long_value` for IDs, family handles, timestamps, and long account/client values; preserve responsive resource rows |
| T-109-04 | Spoofing | support pivot labels | accept | route remains mounted behind host-owned operator authentication; this plan does not add staff identity, role, MFA, or tenant-policy behavior |
| T-109-SC | Tampering | package manager installs | accept | no dependency installation or package-manager task is allowed in this plan |
</threat_model>
